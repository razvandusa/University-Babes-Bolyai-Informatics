# Lab1 SGBD

## How to configure & connect to the database
- Install PostgreSQL.
- Open pgAdmin or the command line.
- Create the database:
```sql
CREATE DATABASE sgbd;
```
- Connect to the database:
- In IntelliJ IDEA, add the database by entering the url, username and password.
- Open the Default Query Console and create these tables and records:
```sql
CREATE TABLE Students (
                          id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
                          name VARCHAR(50),
                          age INT
);

CREATE TABLE Course (
                        id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
                        name VARCHAR(50)
);

CREATE TABLE Enrollment (
                            student_id INT,
                            course_id INT,
                            FOREIGN KEY (student_id) REFERENCES Students(id),
                            FOREIGN KEY (course_id) REFERENCES Course(id),
                            PRIMARY KEY (student_id, course_id)
);

INSERT INTO Students (name, age) VALUES ('Anne', 20);
INSERT INTO Students (name, age) VALUES ('Bob', 23);
INSERT INTO Students (name, age) VALUES ('Jane', 25);
INSERT INTO Course (name) VALUES ('Math');
INSERT INTO Course (name) VALUES ('Science');
INSERT INTO Course (name) VALUES ('History');
INSERT INTO Enrollment (student_id, course_id) VALUES (1, 1);
INSERT INTO Enrollment (student_id, course_id) VALUES (2, 1);
INSERT INTO Enrollment (student_id, course_id) VALUES (3, 1);
INSERT INTO Enrollment (student_id, course_id) VALUES (1, 2);
```
- Create in the root of the module a database configuration file (bd.config)
- The config file should have this structure:
```
jdbc.url=[your database url]
jdbc.user=[your database user]
jdbc.pass=[your database password]
```

## How to run the application
- Make sure the build.gradle file is configured correctly. Include the dependencies for PostgreSQL and JavaFX.
- Build the project using Gradle.
- Run the application using the run configuration.
